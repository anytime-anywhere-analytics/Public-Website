`public/`, so `archive/assets/img/news/x.jpg` used to be served as `/assets/img/news/x.jpg`.
Nothing in this folder is built or deployed — move a file back under `public/` to use it again.

- `assets/people/dhanoa.jpg` — an earlier portrait, replaced by `vaishali.jpg`
- `assets/people/marcel.jpg` — Marcel's earlier portrait, replaced by the hoodie portrait at the same path
